# Castle Keeper

Marketing site for Castle Keeper, a cozy living kingdom simulator by Josh Barnett.

- GitHub Pages (after Pages is enabled): https://barnettj-hash.github.io/castlekeeper-site/
- Canonical site: https://castlekeeper.org/

Publishing source: default branch `main`, folder `/`. Gallery art is in `assets/images/`, and the browser build is in `castle-keeper-webgl/`.
